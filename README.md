  # AutoPilot AI

## Project Objective

Build an autonomous driving system that can perceive the environment, make decisions, and control vehicle movement.

## System Architecture

### Perception
- Camera
- LiDAR
- GPS

### Decision
- RL Agent
- Path Planner

### Control
- Steering
- Brake
- Throttle

## Tech Stack

- Python
- PyTorch
- NumPy
- Pandas
- Matplotlib
- Scikit-Learn
- Git
- GitHub

## Hardware Constraints

- Limited processing power
- Sensor inaccuracies
- Memory limitations

## Software Constraints

- Python dependencies
- Training time requirements
- Dataset size limitations
